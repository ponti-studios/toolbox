# datpiff

Typer CLI for crawling Internet Archive DatPiff-style mixtape collection
listings. Iterates archive.org search results and emits detail URLs for
downstream processing.

## Quick start

```bash
cd apps/datpiff
python3 -m datpiff scrape archiveorg --help
```

## Commands

- `scrape archiveorg` — crawl archive.org collection search results and emit detail URLs
